C++ Dependency Visualizer \& Analyzer



Консольное приложение на современном \*\*C++20\*\* для анализа, проверки на циклы, определения порядка загрузки и визуализации графов зависимостей пакетов. Проект поддерживает работу как с локальными тестовыми репозиториями, так и с удаленными источниками (например, PyPI JSON API).



\---



\## Основные возможности



1\. \*\*Конфигурация через JSON\*\*: Настройка параметров анализа с помощью валидируемых конфигурационных файлов (`nlohmann/json`).

2\. \*\*Получение зависимостей\*\*: 

&#x20;  - Работа с локальными структурированными JSON-файлами репозиториев.

&#x20;  - Загрузка данных с удаленных URL (через встроенный `curl` / PowerShell).

3\. \*\*Построение графа (BFS)\*\*: Некурсивный обход в ширину для сбора прямых и транзитивных зависимостей.

4\. \*\*Анализ циклов\*\*: Обнаружение и вывод циклических зависимостей в графе.

5\. \*\*Порядок загрузки (Topological Sort)\*\*: Вычисление порядка установки/загрузки пакетов методом топологической сортировки (DFS).

6\. \*\*Консольная визуализация (ASCII-дерево)\*\*: Древовидное отображение иерархии пакетов в терминале.

7\. \*\*Графическая визуализация (Mermaid \& HTML)\*\*: 

&#x20;  - Генерация текстового представления на языке диаграмм \*\*Mermaid\*\*.

&#x20;  - Экспорт в standalone `.mmd` файлы.

&#x20;  - Генерация интерактивных `.html` страниц с динамическим рендерингом через CDN Mermaid.



\---



\## Структура проекта



\* \*\*`Config.hpp`\*\* — загрузка, парсинг и валидация параметров из JSON.

\* \*\*`DependencyFetcher.hpp` / `DependencyFetcher.cpp`\*\* — модуль загрузки и разбора зависимостей из файлов или URL.

\* \*\*`DependencyGraph.hpp` / `DependencyGraph.cpp`\*\* — ядро графа: алгоритмы BFS, поиск циклов, топологическая сортировка, построение ASCII-деревьев и генерация Mermaid/HTML.

\* \*\*`main.cpp`\*\* — главная точка входа приложения.

\* \*\*`run.bat`\*\* — Скрипт для Windows автоматизации сборки и пакетного запуска тестов.

\* \*\*`tests/`\*\* — папка с тестовыми репозиториями (`test\_repo.json`, линейные, циклические и ветвящиеся структуры).

\* \*\*`config\_\*.json`\*\* — конфигурационные файлы для демонстрации различных сценариев.
